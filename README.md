# Mi Despensa

App para el móvil con lo que tienes en casa: dónde está cada cosa (nevera, congelador o despensa), qué caduca pronto (en lotes con fechas distintas), tus recetas, con aviso de cuáles usan lo que está a punto de caducar, y estadísticas de lo que se tira.

- Funciona sin conexión y se instala en la pantalla de inicio con el nombre «Mi Despensa».
- Recuerda tus productos habituales para añadirlos con un toque.
- Los datos no están aquí: se guardan en tu repositorio privado `mi-despensa-datos`, en el archivo `despensa.json`.
- Varias personas de casa pueden usarla a la vez; cada cambio queda firmado con el nombre de quien lo hizo.

Este repositorio es público porque GitHub Pages gratuito solo publica repositorios públicos. No contiene ningún dato tuyo.
